# Expense Tracker

## About Project

Expense Tracker is a simple website made to manage daily expenses.

In this project, we can add our expenses and check where our money is spent.

## Technologies Used

* HTML
* CSS
* JavaScript

## Pages

* Login Page
* Dashboard
* Add Expense
* Expense History
* Reports

## Features

* Add new expense
* View total expenses
* Check remaining balance
* View expense history
* Search expenses
* Delete expenses
* Check category-wise expenses

## Advantages

* Easy to use
* Helps to keep expenses in one place
* Saves time
* Easy to check daily spending
* Simple and user-friendly design

## Disadvantages

* No online database
* Data is saved only in the browser
* Not suitable for multiple users
* No real bank account connection
* Data can be lost if browser storage is cleared

## How to Use

1. Open `index.html`
2. Enter name, email and password
3. Go to Dashboard
4. Add your expenses
5. Check History and Reports

## Project Files

* index.html - Login page
* dashboard.html - Main dashboard
* add-expense.html - Add expense page
* history.html - Expense history
* reports.html - Expense reports
* style.css - Website design
* script.js - Website functions
